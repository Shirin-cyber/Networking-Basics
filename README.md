# Networking Basics: My Notes

> Cisco Networking Academy · Networking Basics

These are my notes for Cisco's Networking Basics course. I'm writing them the way I'd explain things to a friend: figuring stuff out as I go and connecting one idea to the next. Way easier to come back to later than the official wording.

---

## So what's this course actually about?

Basically, how networks work, and how to set up and look after a small one, like the kind you'd find in a home or a small office (people call this a **SOHO** network: small office/home office).

It walks through:

- what a network is made of
- the devices inside it
- how those devices talk to each other
- how to figure out what's wrong when something breaks

The internet is part of the picture too. Once you think about it, the internet is just a ton of networks connected to other networks, so the same ideas apply, just bigger.

---

## What I should be able to do by the end

I grouped these so they make more sense to me. It kind of goes from "what even is a network" to "ok now I can build and fix one."

### The big picture

- Explain the important ideas behind how devices communicate on a network
- Explain the different types of networks, what they're made of, and how things connect
- Explain why standards and protocols matter (they're the shared rules, so devices from different companies can actually understand each other)
- Describe the common network media (the stuff data travels through, like cables and wireless)

### Getting devices online

- Set up mobile devices for wireless access
- Configure a wireless router and a wireless client so they connect to the internet securely
- Configure a DHCP server
- Build a fully connected LAN

### How the data actually moves around

- Explain how communication works on Ethernet networks
- Explain what an IP address is and what it does
- Explain how IPv4 addresses are used to communicate and to split networks into segments
- Explain what makes IPv6 addressing different
- Explain how routers connect networks together
- Explain how ARP helps devices talk to each other on a network
- Explain how clients get to internet services
- Explain what the common application layer services do

### When stuff breaks

- Use different tools to test and troubleshoot network connectivity

## Tools I'll be using

### Packet Tracer

Packet Tracer is a simulator that shows what's happening inside a network, and it's used all through the course. So no real routers or switches needed. Everything happens in the software.

If I'm new to it, there's a free short course to start with: [Getting Started with Cisco Packet Tracer](https://www.netacad.com/courses/getting-started-cisco-packet-tracer?courseLang=en-US)

> **Heads up:** the course works on a phone, tablet, or computer, but Packet Tracer activities (plus some other activities, quizzes, and exams) work best on a PC.

### Lab environment

None needed. No equipment, just Packet Tracer.
