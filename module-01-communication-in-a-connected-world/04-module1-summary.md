## 1.1 Network Types

- **Nobody owns the internet.** It's a worldwide collection of networks connected to each other (an **internetwork**) that cooperate using **common standards**.
- That's why it's called a **network of networks**: it's made of thousands of local networks joined together.
- Networks come in different sizes:

| Type | Quick idea |
|---|---|
| **Small home network** | A few computers connected to each other and the internet |
| **SOHO (small office/home office)** | Home or remote office computers sharing resources or connecting to a corporate network |
| **Medium to large** | Corporations and schools, with hundreds or thousands of connected devices |
| **World wide** | The internet itself |

- It's not just computers anymore. Connected devices include **mobile devices** (smartphones, tablets, smartwatches, smart glasses), **home devices** (security systems, appliances, smart TVs, gaming consoles), and **others** (smart cars, RFID tags, sensors and actuators, medical devices).

## 1.2 Data Transmission

- **Data** is the information I put in. There are three kinds:
  - **Volunteered:** I knowingly offer it.
  - **Inferred:** generated by my activities, like credit card use.
  - **Observed:** collected from my devices, like phone location.
- Computers only understand **bits** (0 or 1). **8 bits = 1 byte**.
- Codes like **ASCII** turn letters, numbers, and special characters into bits (one character = 8 bits).
- Input devices turn what I do into binary. Output devices turn binary back into something I can understand.
- To travel, bits become **signals** that move through network **media**:

| Signal | How | Media |
|---|---|---|
| **Electrical** | Pulses of electricity | Copper wire |
| **Optical** | Pulses of light | Fiber-optic cable |
| **Wireless** | Infrared, microwave, or radio waves | Air |

- Homes and small businesses mostly use copper and Wi-Fi. Larger networks use fiber to carry signals reliably over longer distances.

---

## 1.3 Bandwidth and Throughput

- **Bandwidth** = the capacity of a medium to carry data, in bits per second. It's the theoretical max.
- Units go from **bps → Kbps → Mbps → Gbps → Tbps**, each one 1,000 times bigger than the one before.
- **Throughput** = how much data actually gets across in a given time, delays included. It's usually lower than bandwidth.
- **Latency** = the time data takes to travel from one point to another, including delays.
- Throughput is affected by the amount of data, the types of data, and how many network devices are between the source and the destination.
- **The slowest link** on the path limits the throughput of the whole network.
- Speed tests (like speedtest.net) show throughput, and home connections usually have higher download than upload speeds.

---

## How it all connects

Here's what happens when I send a message, with all three topics in one story:

1. I type it, and that's **data** (volunteered, since I chose to send it).
2. My device turns it into **bits** using a code like ASCII.
3. The bits become **signals**: maybe radio waves over Wi-Fi first, then electrical pulses on a cable, then light on fiber, and so on, changing form as the media changes.
4. It crosses a bunch of **local networks**, which together make up the **internet**.
5. How fast it all happens depends on the **bandwidth** (the capacity) but what I actually get is the **throughput**, and the **slowest link** decides the limit.

## Key terms cheat sheet

| Term | What it means |
|---|---|
| **Internet / internetwork** | A worldwide collection of interconnected networks |
| **SOHO** | Small office/home office network |
| **Volunteered data** | Data I knowingly offer |
| **Inferred data** | Data generated by my activities |
| **Observed data** | Data collected from my devices |
| **Bit** | Binary digit, either 0 or 1 |
| **Byte** | A group of 8 bits |
| **ASCII** | A code that represents characters using 8 bits each |
| **Media** | The physical thing signals travel through |
| **Signal** | Electrical or optical patterns (or radio waves) that represent bits |
| **Bandwidth** | The capacity of a medium to carry data (theoretical) |
| **Throughput** | The actual amount of data that gets across in a given time |
| **Latency** | The time data takes to travel from one point to another, including delays |
| **Mbps** | Millions of bits per second |
