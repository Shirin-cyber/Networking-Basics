## 3.1 Wireless Networks

- A phone isn't on one network. It uses **many at once**, each with its own **rules, protocols, and frequencies**, and it has **multiple radios** inside to handle them.

| Technology | What it's for | Key facts |
|---|---|---|
| **Cellular (GSM, 4G/5G)** | Calls, texts, and mobile data | Goes through the carrier's network. This is what the data plan uses. |
| **GPS** | Finding location | Satellites send signals, the phone receives them and works out where it is (within about 10 meters) |
| **Wi-Fi** | Local network and internet access | The phone must be in range of a wireless access point. A **hotspot** is an area with Wi-Fi signal. |
| **Bluetooth** | Accessories (speakers, headphones, smartwatch) | Low power, short range, can connect multiple devices |
| **NFC** | Tap-to-pay | Works within a few centimeters, using electromagnetic fields |

## 3.2 Mobile Device Connectivity

### Wi-Fi

- Use Wi-Fi when possible. It **doesn't use my data plan** and it **saves battery**.
- Stay safe: no passwords in **plaintext**, use a **VPN** for sensitive data, **secure my home network**, and use **WPA2 or higher**.
- To connect: turn Wi-Fi on, pick a network from the list, and enter the password.
- If the network doesn't show up (SSID broadcast off) or doesn't auto-connect, set it up **manually**. The **SSID** (network name) and **passphrase** (wireless password) must match the router setup **exactly**.

### Cellular data

- Plans, limits, and charges **vary a lot** by carrier and plan, so lots of people use cellular only when there's no Wi-Fi.
- Phones **prefer Wi-Fi** (if they can connect to the access point and get an IP address), then fall back to **cellular**. Switching between networks, even 4G to 3G, doesn't drop the connection.
- Turn cellular data on or off in Settings (Android: Mobile Networks > Data enabled, iOS: Cellular Data).

### Bluetooth

- It's **simple, automatic, and low power**, and up to **eight** devices can connect at once.
- Used for hands-free headsets, keyboards and mice, car and home stereos, car speakerphones, **tethering**, and portable speakers.
- **Pairing**: both Bluetooth radios are on, one device searches, and the other must be in **discoverable mode**. A **PIN** may be needed once, and then it's saved so the devices reconnect automatically.

### All together

- Wi-Fi, cellular, and Bluetooth can all run **at the same time**, each with a different job (like music over Bluetooth, internet over Wi-Fi, and texts over cellular).
- Menus change with OS updates, so check the **manufacturer's documentation**.

## How it all connects

Now I can replay Kishori's evening from the Module 3 README, and this time I actually know what's going on:

| What happened | What's behind it |
|---|---|
| **Shridhar's call comes in** | The **cellular network** carries the voice |
| **Her call moves to the car speakers** | **Bluetooth**, probably already paired, since the PIN is saved and devices reconnect when in range |
| **She searches for the restaurant** | **Cellular data** (the data plan), since she's out and about |
| **She gets directions** | **GPS** works out her location, and the data plan loads the map |
| **She pays for the food** | **NFC**, if she tapped her phone (the story doesn't say how she paid) |
| **At home** | Her phone prefers **Wi-Fi**, which gets an IP address from the router, and saves her data plan |

The thing that surprised me most is that all of this happens on one device, and I never have to think about it.

## Key terms cheat sheet

| Term | What it means |
|---|---|
| **Cellular network** | The carrier's network for calls, texts, and mobile data |
| **Data plan** | The cellular data allowance from the carrier, often metered |
| **GPS** | Global Positioning System, which uses satellite signals to find location |
| **Wi-Fi** | Wireless connection to a local network and the internet through an access point |
| **Hotspot** | An area where Wi-Fi signals are available |
| **Bluetooth** | Low-power, short-range wireless for accessories |
| **NFC** | Near Field Communication, for tap-to-pay at very close range |
| **SSID** | The name of a wireless network |
| **Passphrase** | The wireless password |
| **WPA2** | A Wi-Fi security option (use WPA2 or higher) |
| **VPN** | A connection to use when sending sensitive data (the course hasn't explained how it works yet) |
| **Plaintext** | Unencrypted text, so never send passwords this way |
| **Pairing** | Two Bluetooth devices setting up a connection to share resources |
| **Discoverable mode** | A device setting that lets other Bluetooth devices find it |
| **PIN** | A code that may be needed during pairing, then saved |
| **Tethering** | Sharing one device's network connection with another |
