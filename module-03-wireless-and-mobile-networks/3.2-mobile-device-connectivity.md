## 3.2.1 Mobile devices and Wi-Fi

Mobile devices let me work, learn, play, and communicate from wherever. I don't need to be stuck in one spot to send and receive voice, video, and data. Some real examples from the text:

- Wireless is available in lots of places, like **internet cafes** in many countries.
- **College campuses** use wireless so students can sign up for classes, watch lectures, and submit assignments, even in areas where physical network connections aren't available.
- Mobile devices keep getting more powerful, so a lot of stuff that used to need a big computer on a wired network can now be done on a phone over wireless.

### Why use Wi-Fi when I can

Almost every mobile device can connect to Wi-Fi, and it's a good idea to use it when possible for two reasons:

1. Data used over Wi-Fi **doesn't count against my cellular data plan**.
2. Wi-Fi radios use **less power** than cellular radios, so it **saves battery**.

**Connecting the dots:** the first one ties back to 2.3.4, where cellular data is usually metered and extra usage can cost money. The second one goes with 3.1.2: phones have multiple radios, and apparently the Wi-Fi one is the lighter one on battery.

### Staying safe on Wi-Fi

Wi-Fi needs security like any other Wi-Fi device. Four precautions:

- **Never** send login or password info as **plaintext** (unencrypted text).
- Use a **VPN** when possible if I'm sending sensitive data.
- **Turn on security** on my home network.
- Use **WPA2 or higher** encryption.

The course doesn't explain what a VPN or WPA2 actually is here, so I'll watch for that later.

## 3.2.2 Wi-Fi settings

Two of the most popular mobile operating systems are **Android** and **Apple iOS**, and both have settings to connect to wireless networks.

**To connect (Android or iOS):**

1. Be within range of a Wi-Fi network.
2. Turn on Wi-Fi. The device searches and shows a **list of available networks**.
3. Touch the network I want.
4. Enter the password if it needs one.

### What the phone does by itself

- If I move **out of range**, it tries to connect to **another Wi-Fi network in range**.
- If **no Wi-Fi** is in range, it switches to the **cellular data network**.
- With Wi-Fi on, it **automatically reconnects** to networks I've used before.
- For a **new** network, it either shows a list of available ones or asks if I want to connect.

## 3.2.3 Configure mobile Wi-Fi connectivity

Sometimes the phone doesn't prompt me to connect to a network. Two reasons:

- The network's **SSID broadcast** is turned off, or
- The device isn't set to **connect automatically**.

When that happens, I set it up **manually**.

Two terms to keep straight:

- **SSID** = the name assigned to a wireless network.
- **Passphrase** = what we normally call the "wireless password."

And a big one: the SSID and passphrase have to be typed **exactly** as they were entered in the **wireless router setup**, or the device won't connect properly.

### Android: connect manually

1. Settings > **Add network**
2. Enter the network **SSID**
3. Touch **Security** and pick a security type
4. Touch **Password** and enter the password
5. Touch **Save**

### iOS: connect manually

1. Settings > Wi-Fi > **Other**
2. Enter the network **SSID**
3. Touch **Security** and pick a security type
4. Touch **Other Network**
5. Touch **Password** and enter the password
6. Touch **Join**

The iOS step order reads a bit odd to me (step 4 especially), so I'd double-check it on a real phone. The course also says mobile operating systems get updated all the time and manufacturers customize them, so the steps might not match my device exactly. The manufacturer's website usually has online manuals for each device.

**Connecting the dots:** "SSID broadcast turned off" and "wireless router setup" both point at a router setting I'd configure myself. That fits the module goal of configuring a wireless router later in the course.

## 3.2.4 Configure cellular data settings

Most carriers offer cellular data plans, but **bandwidth limits and charges vary a lot** between carriers, and even between plans from the same carrier. That's why a lot of people only use cellular data when Wi-Fi isn't available.

### Turning cellular data on or off

| OS | Path |
|---|---|
| **Android** | Settings > touch **More** under Wireless and Networks > **Mobile Networks** > **Data enabled** |
| **iOS** | Settings > **Cellular Data** > turn it on or off |

### How the phone picks a network

Mobile devices are preprogrammed so they:

1. Use a **Wi-Fi network** for the internet if there is one and the device can connect to the access point **and get an IP address**.
2. If there's no Wi-Fi, use **cellular data** (if it's set up).

Most of the time I wouldn't even notice a switch. For example, when a phone moves from **4G coverage to 3G coverage**, the **4G radio shuts off and the 3G radio turns on**, and the connection **isn't lost**.

**Connecting the dots:**

- "Receive an IP address" is the router's job from 2.3.2, where the wireless integrated router provides client IP addressing info. So that's how my phone gets its address on Wi-Fi.
- The 4G-to-3G switch is another sign that a phone really does have separate radios for different networks.

## 3.2.6 Simple connectivity with Bluetooth

Mobile devices connect in a lot of ways, but **cellular and Wi-Fi can be hard to configure** and need extra equipment like **towers and access points**. And cables aren't practical for stuff like headsets and speakers.

So **Bluetooth** is the simple option for connecting mobile devices to each other and to wireless accessories. It's:

- **wireless**
- **automatic**
- very **low power**, so it saves battery

**Up to eight** Bluetooth devices can be connected at the same time.

### Common uses

| Use | What it is |
|---|---|
| **Hands-free headset** | A small earpiece with a mic for making and receiving calls |
| **Keyboard or mouse** | Connect one to a mobile device to make input easier |
| **Stereo control** | Connect to a home or car stereo to play music |
| **Car speakerphone** | A device with a speaker and mic for calls |
| **Tethering** | Connect to another mobile device or computer to **share a network connection** (also possible over Wi-Fi or a USB cable) |
| **Mobile speaker** | A portable speaker for high-quality audio without a stereo system |

**Connecting the dots:** this settles it for Kishori. When her call moved from her phone to the **car speakers**, that was Bluetooth, matching the **car speakerphone** and **stereo control** examples. Also, tethering connects to 2.3.4: one device shares its cellular connection so another one can get online.

## 3.2.7 Bluetooth pairing

**Pairing** = two Bluetooth devices set up a connection so they can share resources.

### How it works

- Both devices have their **Bluetooth radios on**.
- One device **searches** for others.
- The others have to be in **discoverable mode** (also called **visible**) so they can be found.

When a device is discoverable and another device asks, it shares:

- its **name**
- its **Bluetooth class**
- the **services** it can use
- **technical info**, like its features or the Bluetooth specification it supports

### The PIN

During pairing, I might need to enter a **PIN** to **authenticate** the pairing. It's often a number, but it can also be a numeric code or a **passkey**. The PIN gets **stored**, so I don't need to enter it again next time. That's why a headset and phone pair automatically when the headset is turned on and in range.

**Connecting the dots:** that's the same "should reconnect automatically" thing from the Windows video, and now I know why. The pairing info is saved.

### Android: pair a Bluetooth device

1. Put the device in **discoverable mode** (follow its instructions)
2. Find the device's **connection PIN** (check its instructions)
3. Settings > **Wireless and networks**
4. Touch **Bluetooth** to turn it on
5. Touch the **Bluetooth tab**
6. Touch **Scan for devices**
7. Touch the **discovered device**
8. **Type the PIN**
9. Touch the **device name again** to connect

### iOS: pair a Bluetooth device

1. Put the device in **discoverable mode**
2. Find the device's **connection PIN**
3. Settings > **Bluetooth**
4. Touch **Bluetooth** to turn it on
5. Touch the **discovered device**
6. **Type the PIN**

Same warning as before: mobile operating systems are updated often, so check the manufacturer's documentation for the latest steps on a specific model.

## What I want to remember

- **Use Wi-Fi when possible.** It doesn't use my data plan and it saves battery. Protect it with WPA2 or higher, avoid sending passwords in plaintext, and use a VPN for sensitive data.
- **SSID** = network name, **passphrase** = wireless password. Both must be typed **exactly** like on the router.
- Phones **prefer Wi-Fi**, fall back to **cellular**, and switch between them (and between 4G and 3G) without dropping the connection.
- **Bluetooth** is simple, automatic, and low power, with up to **eight** devices at once. It's used for headsets, keyboards, car speakers, tethering, and more.
- **Pairing** needs the Bluetooth radios on and one device in **discoverable mode**. A **PIN** may be needed once, then it's saved.
- OS menus change often, so when in doubt, check the **manufacturer's documentation**.
