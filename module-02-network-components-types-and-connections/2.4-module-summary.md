## 2.1 Clients and Servers

- A **host** is any computer that takes part directly in network communication. It can be a **client**, a **server**, or **both**, and the **software** installed on it decides which.
- **Servers** provide information (email, web pages, files). **Clients** request and display it. Each service needs its own server software.

| Type | Server runs | Client uses |
|---|---|---|
| **Email** | Email server software | Mail client software (like Outlook) |
| **Web** | Web server software | A browser |
| **File** | File storage in a central location | Client software (like File Explorer) |

- **Peer-to-peer (P2P) networks:** computers act as both clients and servers. They're easy, simple, and cheap, but there's no centralized administration, they're not very secure, they don't scale, and performance can drop when a device does both jobs.
- **P2P applications:** every client is also a server. **Hybrid** ones use a central index server to find resources on other peers.
- One computer can run **multiple server programs** and **multiple client programs** at the same time.

## 2.2 Network Components

- The course uses **symbols** for network equipment: **intermediate devices** (router, wireless router, switch, wireless access point), **end devices** (laptop, printer, smartphone, IP phone), and **media** (LAN, WAN, wireless, and the Cloud, which stands for another network on the internet).
- **Network infrastructure** is the platform that supports the network. It has 3 categories of hardware:

| Category | What it is |
|---|---|
| **End devices** | Hosts. The source or destination of a message, and the way users connect to the network. Each is identified by an address. |
| **Intermediate devices** | The devices in the middle that connect things together |
| **Network media** | What connects the devices (cables, or invisible radio frequencies and infrared for wireless) |

- End devices aren't just computers. They include network printers, phones, security cameras, mobile devices, and even card readers and barcode scanners.

## 2.3 ISP Connectivity Options

- An **ISP** links my home network to the internet. It can be a cable company, a phone company, a cellular carrier, or an independent provider that leases bandwidth on someone else's infrastructure. Many also offer extras like email, storage, and hosting.
- ISPs connect to each other in a **hierarchy** so traffic generally takes the shortest path. The **internet backbone** is made of **fiber-optic cable**, underground and under the sea.
- At home:
  - **Modem only:** direct connection, but **unprotected**, so don't use it.
  - **Wireless integrated router:** the common, secure option. It includes a **switch** (wired hosts), a **wireless AP** (wireless hosts), **IP addressing** info, and **security**.

| Connection | Quick idea |
|---|---|
| **Cable** | Internet over the same coaxial line as cable TV, using a cable modem |
| **DSL** | Internet over a phone line split into voice, download, and upload channels. Slower the farther you are from the central office. |
| **Cellular** | Works anywhere there's a signal, but data is usually metered |
| **Satellite** | Good where there's no cable or DSL, but needs a clear line of sight |
| **Dial-up** | Cheap but very slow. A last resort. |
| **Fiber** | Direct fiber in cities, with higher bandwidth and more services |

- What I can get depends on **where I live** and **which providers are available**.

## How it all connects

Here's my best guess at what happens in Kishori's hospital, using everything from this module. The course hasn't spelled out her exact setup, so this is me putting the pieces together:

1. She types notes on her **laptop**, which is an **end device** and a **client**.
2. The notes travel over **network media**, probably wireless in a patient room, to an **intermediate device** like a wireless access point or a switch.
3. The notes get stored on a **server** (also an end device, running server software), so patient records live in one central place.
4. At the nursing station, her **desktop** is another **client**. It asks the server for the patient's record and displays it, with her new notes included.
5. If any of this needs the internet, the traffic goes through a **router**, then a **modem**, then her **ISP**, then onto the **backbone**, out to the rest of the world.

## Key terms cheat sheet

| Term | What it means |
|---|---|
| **Host** | A computer that takes part directly in network communication (same as an end device) |
| **Client** | A host with software to request and display information from a server |
| **Server** | A host with software to provide information to other hosts |
| **P2P network** | A network where computers act as both clients and servers |
| **P2P application** | An app where each device is both client and server in the same communication |
| **End device** | The source or destination of a message |
| **Intermediate device** | A device in the middle of the network, like a router, switch, or access point |
| **Network media** | What carries signals between devices |
| **Network infrastructure** | End devices + intermediate devices + network media |
| **LAN / WAN** | Local Area Network / Wide Area Network |
| **The Cloud** | A symbol for another network on the internet |
| **ISP** | Internet Service Provider, which links a network to the internet |
| **Internet backbone** | The high-speed fiber links connecting ISPs around the world |
| **Wireless integrated router** | A router, switch, and wireless AP in one box |
| **DSL** | Digital Subscriber Line, internet over a phone line |
