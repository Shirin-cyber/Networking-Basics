## 2.2.2 Network infrastructure

A message's trip from the source to the destination can be super simple, like one cable connecting two computers. Or it can be huge, like a network that spans the whole planet.

**Network infrastructure** = the platform that supports the network. It's the stable, reliable channel that all our communication runs over.

### The 3 categories of hardware

1. **End devices**
2. **Intermediate devices**
3. **Network media**

Devices and media are the **physical parts (the hardware)** of the network. A lot of it is easy to see, like a laptop, PC, switch, router, wireless access point, or the cables connecting them.

But not all of it is visible. With **wireless media**, the messages travel through the air using **invisible radio frequencies or infrared waves**.

**Connecting the dots:**

- "Media" is the same thing from 1.2.3: the physical thing signals travel through (copper, fiber, or air). So these three categories are really just: **the devices at the edges, the devices in the middle, and what's between them.**

## 2.2.3 End devices

End devices are the ones people know best. They're also called **hosts**, and they act as the **interface between users and the underlying communication network**. So they're the way I actually get onto the network.

### Examples

- **Computers:** workstations, laptops, file servers, web servers
- **Network printers**
- **Telephones and teleconferencing equipment**
- **Security cameras**
- **Mobile devices:** smartphones, tablets, PDAs, and wireless debit/credit card readers and barcode scanners

An end device (host) is either the **source** or the **destination** of a message sent over the network.

### How do they find each other?

Using **addresses**. Each host needs a unique address, and when a host starts communicating, it uses the **address of the destination host** to say where the message should go.

**Connecting the dots:**

- Servers are on the list, so a file server or web server counts as an end device too. That fits with 2.1, where I learned servers are hosts running server software. Not a separate type of thing.
- I'm guessing these addresses are **IP addresses**. The course outline has a whole module on IPv4 addresses (Module 8), so that's probably where this goes.
- Also, a card reader or a barcode scanner counts as an end device. I wouldn't have thought of those as hosts, but they send and receive messages on a network, so they are.
