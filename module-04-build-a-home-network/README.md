## 4.0 Introduction

### 4.0.1 Why should I take this module?

Kishori and Shridhar are back, and this time they're doing the dishes after dinner. She's putting dishes away while watching a favorite movie on her **tablet**, and it gets her wondering something.

She asks Shridhar whether her tablet works exactly like her mobile phone. His answer:

- Some tablets **do** use a mobile network.
- But hers works on the **Wi-Fi network in the house**.

Kishori says she knows the Wi-Fi must come from **that box in the corner of the living room**. And that's literally all she knows about it.

So Shridhar explains: that box is a **home router**, and it's connected to the internet. Here's what he tells her about it:

- Home routers typically have **two main types of ports**: **Ethernet ports** and **internet ports**.
- Many also have a **radio antenna** and a **built-in wireless access point**, on top of the wired ports.
- Kishori mostly uses the **wireless** side.

Then Shridhar gets worried. Since his mom didn't even know what the router was, she probably **never changed the default password** on it. So he logs into the router and makes some changes to keep her network and devices safer.

The module wraps up with two questions for me: have I ever set up a router, and have I thought about **secure communication over wireless devices**? This module is meant to give me the knowledge to **build a home network** and set up wireless devices to communicate **securely**.

**Connecting the dots:**

- The "box in the corner" has come up in every Kishori story, and now it finally has a name. It's the **wireless integrated router** from 2.3.2. The **built-in wireless access point** here is the same one from that section, and I'm guessing the Ethernet ports are where the **built-in switch** plugs into wired devices.
- The default password worry connects to the Wi-Fi safety tips from 3.2.1, like **enabling security on my home network** and using **WPA2 or higher**. Leaving factory settings alone is kind of like leaving the front door unlocked.
- The tablet part ties to Module 3: a tablet can use **cellular** like a phone, but hers uses **Wi-Fi**.

### 4.0.2 What will I learn in this module?

**Module title:** Build a Home Network

**Module objective:** Configure an integrated wireless router and wireless client to connect securely to the internet

Here's what's in it:

| Topic | What I'll be able to do |
|---|---|
| **Home network basics** | Describe the components required to build a home network |
| **Network technologies in the home** | Describe wired and wireless network technologies |
| **Wireless standards** | Describe Wi-Fi |
| **Set up a home router** | Configure wireless devices for secure communications |

A few thoughts before I start:

- **Home network basics** probably covers the pieces I need to build a home network, a lot of which I've already seen in Module 2.
- **Network technologies in the home** sounds like wired (cables) versus wireless, and when you'd use each.
- **Wireless standards** is all about Wi-Fi. I'm guessing there are different versions, and that's what makes some connections faster than others.
- **Set up a home router** is the hands-on one, and it's the same goal listed in the course introduction: configure a wireless router and a wireless client so they connect to the internet **securely**. This is probably what Shridhar did to his mom's router.
