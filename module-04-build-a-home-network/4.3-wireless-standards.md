## 4.3.1 Wi-Fi networks

Remember how I wondered in 4.2 whether 802.11 is what Wi-Fi is built on? Yep. This section confirms it.

### Why standards exist

A bunch of **standards** were created so wireless devices can actually communicate with each other. They spell out things like:

- which part of the **RF spectrum** is used
- the **data rates**
- **how the information is transmitted**
- and more

### Who's behind them

| Organization | What it does |
|---|---|
| **IEEE** (Institute of Electrical and Electronics Engineers) | The main organization that creates wireless technical standards |
| **Wi-Fi Alliance** | Tests wireless LAN devices from **different manufacturers** |

- The **IEEE 802.11** standard governs the **WLAN** environment.
- There are **amendments** to 802.11 that describe the characteristics of different wireless standards.
- Wireless LAN standards use the **2.4 GHz and 5 GHz** bands, and together these technologies are called **Wi-Fi**.
- The **Wi-Fi logo** on a device means the equipment **meets the standards** and should work with other devices that use the same standard.

### Keep an eye on new standards

Wireless standards keep improving connectivity and speed, and manufacturers put new standards into their products **fast**. So it's worth being aware of new ones when they come out.

**Connecting the dots:**

- This is the "importance of standards and protocols" goal from the course intro, and it echoes 1.1.3, where the internet works because everyone cooperates using **common standards**. The Wi-Fi Alliance is basically the group that checks that a router from one company will work with a phone from another.

## 4.3.2 Wireless settings

The course shows the **Basic Wireless Settings** screen in **Packet Tracer**. Wireless routers using 802.11 have a few settings to configure:

| Setting | What it does | Default |
|---|---|---|
| **Network Mode** | The type of technology the router must support, like 802.11b, 802.11g, 802.11n, or **Mixed Mode** | |
| **Network Name (SSID)** | Identifies the WLAN. All devices that want to join must use the **same SSID**. | |
| **Standard Channel** | The channel communication happens on | **Auto**, so the access point picks the best channel |
| **SSID Broadcast** | Whether the SSID is **broadcast to all devices in range** | **Enabled** |

SSID stands for **Service Set Identifier**.

### Network mode

802.11 can give better throughput depending on the wireless environment:

- If **all devices** use the **same 802.11 standard**, I get the **maximum speed** for that standard.
- If the access point is set to accept **only one** standard, devices that don't use it **can't connect**.
- **Mixed mode** allows devices using **any of the existing Wi-Fi standards**. That makes it easy for **older devices** that can't use the latest standards.

### The SSID

When building a wireless network, the wireless devices have to join the right WLAN, and the **SSID** is how that happens.

- It's a **case-sensitive, alphanumeric** string, up to **32 characters**.
- It's sent in the **header of every frame** sent over the WLAN.
- It tells wireless devices, called **wireless stations (STAs)**, which WLAN they belong to and who they can communicate with.
- Basically, it's the **name of the network**.

### SSID broadcast

- Wireless routers usually **broadcast** their SSID by default, so clients can **discover the network name automatically**.
- If I **disable** the broadcast, I have to **type the SSID manually** on each device.
- Turning it off can make it harder for **legitimate** clients to find the network. But **just turning it off isn't enough** to keep unauthorized clients out.
- All wireless networks should use the **strongest available encryption** to restrict access.

**Connecting the dots:**

- This explains 3.2.3. When a phone didn't prompt me to connect, one reason was that the **SSID broadcast was turned off**, so I'd have to enter it by hand. And "case-sensitive" is probably why the SSID has to be typed *exactly*.
- Hiding the SSID sounds like security, but it isn't really. It only hides the name. **Encryption** is what actually protects the network, and that's why 3.2.1 said to use **WPA2 or higher**.
- "Frames" is a new word. The course doesn't explain it here, so I'll watch for it later.

## What I want to remember

- **Standards** let wireless devices from different companies communicate. The **IEEE** creates them, and the **Wi-Fi Alliance** tests devices from different manufacturers.
- **IEEE 802.11** governs WLANs. Together, the 2.4 GHz and 5 GHz wireless LAN technologies are called **Wi-Fi**.
- The **Wi-Fi logo** means a device meets the standards.
- Key router settings: **Network Mode**, **SSID**, **Standard Channel** (Auto by default), and **SSID Broadcast** (Enabled by default).
- If all devices use the **same standard**, speeds are maximized. **Mixed mode** lets older devices connect.
- The **SSID** is the network name: case-sensitive, up to 32 characters.
- **Turning off SSID broadcast is not real security.** Use the **strongest encryption** available.
