## 4.1 Home Network Basics

- A home network is really **two networks**: the **provider's public network** (cable or DSL) and my **local network**.
- The provider's network doesn't use the same protocols and transmission methods as Ethernet, so a **modem** converts the signals. Some home devices have the modem **built in**.
- A **wireless router** is called a router because it **connects two networks**: the local one (wired and wireless) and the one on the internet side.
- Wired and wireless devices usually share the **same local network**, so they get IP addresses on the same network.

| Router port | What it does |
|---|---|
| **Ethernet / LAN port** | Connects to the router's **internal switch**. All devices here are on the same local network. |
| **Internet port** | Connects to a **different network**, usually the cable or DSL modem |

- Lots of devices can hang off a home network: computers, gaming systems, smart TVs, printers, scanners, cameras, phones, and climate controls. This is the **home WLAN**.

## 4.2 Network Technologies in the Home

### Wireless

Home wireless uses the **unlicensed 2.4 GHz and 5 GHz** bands (no permit needed).

| | Bluetooth | 802.11 (Wi-Fi) |
|---|---|---|
| **Bands** | 2.4 GHz | 2.4 GHz and 5 GHz |
| **Speed and range** | Low speed, short range | Better range and throughput (higher power) |
| **Good at** | Many devices at once: mice, keyboards, printers, audio | Connecting devices to a LAN and the internet |

### Wired

- **Ethernet** is the most common wired protocol, and some tasks are better with a wired connection that isn't shared.
- Devices connect with **UTP patch cables** with **RJ-45** connectors. **Category 5e** (4 twisted pairs) is the most common. **Powerline** is an option if a house has no Ethernet wiring.

| Cable | Key point |
|---|---|
| **UTP (Cat 5e)** | 4 twisted pairs to reduce interference |
| **Coaxial** | Inner wire, insulating layer, conducting shield, outer jacket |
| **Fiber-optic** | Glass or plastic, as thin as a hair, very high bandwidth over long distances |

## 4.3 Wireless Standards

- **Standards** make sure wireless devices can communicate. The **IEEE** creates them, and **IEEE 802.11** governs WLANs. Together, the 2.4 and 5 GHz wireless LAN technologies are called **Wi-Fi**.
- The **Wi-Fi Alliance** tests devices from different manufacturers. The **Wi-Fi logo** means a device meets the standards.

| Router setting | What it does |
|---|---|
| **Network Mode** | Which 802.11 technologies the router supports (b, g, n, or **mixed mode**) |
| **SSID** | The network name. It's case-sensitive and up to 32 characters. |
| **Standard Channel** | The channel used. It's **Auto** by default. |
| **SSID Broadcast** | Whether the name is announced to devices in range. It's **enabled** by default. |

- If all devices use the **same standard**, speeds are maximized. **Mixed mode** (also called **legacy mode**) lets older devices connect.
- **Hiding the SSID is not real security.** Use the strongest encryption available.

## 4.4 Set Up a Home Router

### First-time setup

- Connect a computer to a **LAN port** with an Ethernet cable. **Never** the Internet port.
- If the router has a built-in modem, check the connection type: cable uses a **coaxial** terminal and DSL uses an **RJ-11** phone-style port.
- The computer should get an IP address automatically from the router's **DHCP server**.

### Design questions

| Question | Takeaway |
|---|---|
| **What should I name my network?** | Don't include the brand or model. Default settings and weaknesses are easy to find online. |
| **What devices will connect?** | If some are older, turn on **legacy/mixed mode** |
| **How do I add new devices?** | Consider **guest access**, an open SSID that only gets internet access |

### The setup flow (from the Packet Tracer activity)

1. Connect the devices: coax from the splitter to the TV and the cable modem, then copper cables from the modem to the router's internet port and from the PCs to the router's LAN ports.
2. Set the PC to **DHCP**, and note the **default gateway** (the router's address).
3. Open a browser, enter the default gateway address, and log in with the **default credentials**.
4. **Change the default password**, limit the number of users, and **save settings** after every change.
5. Set up wireless: enable **2.4 GHz**, set the **SSID**, choose **WPA2 Personal**, and set a **passphrase**.
6. Connect a wireless client using the passphrase as the **pre-shared key**.
7. Test connectivity from every device.

If I were setting up a real router, my checklist would be:

- [x] Connect my computer to a **LAN port** (not the Internet port)
- [x] Confirm the computer has an **IP address** from the router's DHCP
- [x] Log in at the **default gateway** address
- [x] **Change the default password**
- [x] Name the network without the **brand or model**
- [x] Pick the right mode (**mixed/legacy** if I have older devices)
- [x] Turn on **WPA2 or higher** with a strong **passphrase**
- [x] **Save settings**, then test it from a wired and a wireless device

## Key terms cheat sheet

| Term | What it means |
|---|---|
| **Modem** | Converts the provider's signals so my network can use them |
| **Wireless router** | Joins the local network to the internet side, and includes a switch and wireless AP |
| **Internet port** | The router port that connects to another network (like the modem) |
| **Ethernet / LAN port** | Router ports connected to the internal switch |
| **WLAN** | Wireless local area network |
| **2.4 GHz / 5 GHz** | The unlicensed frequency bands used for home wireless |
| **IEEE 802.11** | The standard that governs WLANs (Wi-Fi) |
| **Wi-Fi Alliance** | The group that tests wireless devices from different manufacturers |
| **SSID** | The wireless network name (case-sensitive, up to 32 characters) |
| **STA** | A wireless station, which is any wireless device on the WLAN |
| **Mixed / legacy mode** | A setting that lets older Wi-Fi devices connect |
| **UTP / RJ-45 / Cat 5e** | Twisted-pair Ethernet cable, its connector, and the most common grade |
| **RJ-11** | The phone-style connector used by DSL |
| **Powerline** | A way to spread wired connectivity through a home without Ethernet wiring |
| **DHCP** | The service that automatically hands out IP addresses |
| **Default gateway** | The device (the router) that gives the home network access to outside networks |
| **Pre-shared key / passphrase** | The wireless password |
| **WPA2 Personal** | A wireless security mode that requires a passphrase |
| **Guest access** | A special SSID that only allows internet access |
