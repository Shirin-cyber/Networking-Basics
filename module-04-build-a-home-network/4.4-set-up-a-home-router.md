## 4.4.1 First-time setup

Many home routers come with an **automatic setup utility** for the basic settings. Most of these need a **PC or laptop connected to a wired port** on the router. If I don't have a device with a wired connection, I might need to set up the **wireless client software** on a laptop or tablet first.

### Connecting with a cable

1. Plug an **Ethernet patch cable** into the network port on the computer.
2. Plug the other end into a **LAN port** on the router.
3. **Don't** plug it into the port labeled **"Internet."** That one is for the **DSL or cable modem**.

Some routers have a **built-in modem**. If mine does, I should check that the connection type matches my internet service:

| Connection | What the router has |
|---|---|
| **Cable modem** | A **coaxial terminal** that takes a **BNC-type** connector |
| **DSL** | A port for a **telephone-type cable**, usually an **RJ-11** connector |

**Connecting the dots:** the internet port vs. LAN port thing is exactly what 4.1.3 said. And RJ-11 (phone cable) is different from the **RJ-45** from 4.2.2, which is the Ethernet connector.

### Getting an IP address

Once the computer is connected, and the **link lights on the NIC** show a working connection, the computer needs an **IP address**.

- Most routers are set up so the computer gets one **automatically from a DHCP server** that's already running on the router.
- If it doesn't get one, I check the router documentation and set up the PC or tablet manually with:
  - a unique **IP address**
  - a **subnet mask**
  - a **default gateway**
  - **DNS** information

**Connecting the dots:** the DHCP part is from the course goals ("configure a DHCP server"). Looks like a home router is a DHCP server out of the box. The subnet mask, default gateway, and DNS are new words, and I'm guessing they come with the IP address modules later on.

## 4.4.2 Design considerations

Before I start configuring, I should think about **how the network will be used**. The goal is to avoid two problems: a setup that **limits** what I can do, and a network that's **unprotected**. There are three questions to ask:

### 1. What should my network be called?

- If **SSID broadcast is on**, every wireless client in range can see the name.
- The SSID can give away too much info to strangers. **Don't put the device model or brand in it.**
- Why? Default settings for devices are **easy to find online**, and some have **known security weaknesses**.

### 2. What types of devices will connect?

- Wireless devices have radios that work in a **specific frequency range**.
- A device with only an **802.11 b/g** radio **won't connect** if the router only accepts **802.11n or ac**.
- If **all devices** support the **same standard**, the network runs at its **best speed**.
- If some devices don't support **n or ac**, I need to turn on **legacy mode**. What it includes varies by router, but it can combine **a, b, g, n, and ac**.
- Note: some routers call legacy mode **mixed mode**.

### 3. How do I add new devices?

- Who can get on my network should depend on **how I plan to use it**.
- Some routers have **guest access**: a special SSID area that allows **open access**, but **only to the internet**.

**Connecting the dots:**

- Legacy mode and mixed mode (from 4.3.2) are the same thing. It's the setting that lets older devices connect.
- Guest access reminds me of the guest and public hotspots from 3.1.3. And since it's "internet only," I'm guessing guests can get online but can't reach my other devices. The text doesn't say that outright.
- The "don't put the brand in the SSID" tip is the kind of thing I'd never have thought of.

## 4.4.3 Video: Wireless router and client configuration

This is a **Packet Tracer** activity. I play a networking student helping a friend connect her home to her ISP, which is a **cable company** that offers **TV and internet**.

### Step 1: Connect the devices

The cables used are **coaxial** and **copper straight-through**.

**Cable splitter, TV, and cable modem (coaxial):**

1. Connect the cable modem to the cable splitter: coaxial cable from the splitter's **coaxial one** port to the cable modem's **port 0**.
2. Connect the TV: coaxial cable from the TV to the splitter's **coaxial two** port.
3. Now the TV should turn on and show a picture.

**Cable modem, router, and PCs (copper straight-through):**

4. Connect the **cable modem** to the **internet port** on the home wireless router.
5. Connect the **office PC's FastEthernet0 port** to the router's **GigabitEthernet 1** port.
6. Connect the **bedroom PC** the same way (the video leaves this for me to do).

**Connecting the dots:** this is 2.3.3 in real life. The cable company's coax carries **TV and internet together**, so the **splitter** sends one branch to the TV and one to the modem. And the "copper straight-through" cable is just an Ethernet patch cable.

### Step 2: Check the office PC's IP addressing

1. Click the office PC > **Desktop** tab > **IP Configuration**.
2. It starts on **static**. Switch it to **DHCP** so it asks the router for an address (a DHCP server is usually set up on the router from the factory).
3. If it doesn't get an address right away, click **fast forward**.
4. Take note of the **default gateway**, which is the router's IP address. The transcript says "192.1680.1," which looks like a typo for **192.168.0.1**.

### Step 3: Log into the router

1. Close IP Configuration and open the **web browser**.
2. Type the **default gateway address** and go.
3. New routers have **default credentials**. (You can find lists of default passwords online, like for Netgear.) On the Packet Tracer router, **admin** is both the username and the password.

The interface has **menus along the top**, and some have **submenus**. The **Wireless** menu has **five** submenus. Remember to click **Save Settings** at the bottom after **every** change.

### Step 4: Change the router settings

**On the Setup tab:**

- Limit the number of users to **10**.

A heads-up from the video: if I change DHCP settings from a device that **uses that DHCP server**, I can **lose connectivity**. If that happens, re-enter the router's IP address to reconnect. Sometimes I need to **renew my IP configuration** too.

**Change the default router password** (Administration menu):

- Set the new password, click **Save Settings**, then log in again with **admin** and the new password.

**Set up the wireless network** (Wireless menu):

1. Enable the **2.4 GHz** network.
2. Change the network name to **MyHome**.
3. Save.
4. Open the **wireless security** submenu, set the 2.4 GHz **security mode** to **WPA2 Personal**, and enter the passphrase.
5. Save.

### Step 5: Connect the laptop

1. Click the laptop > **Desktop** tab > **PC Wireless**.
2. Open the **Connect** menu and click **Connect**.
3. Enter the passphrase as the **pre-shared key** and click **Connect**.
4. Check the **Link Information** menu. It should say I connected successfully to the access point.
5. Open **IP Configuration**. The laptop should now have an IP address starting with **192**. If not, fast forward.

### Step 6: Test connectivity

1. Open the **web browser** and go to **skillsforall.srv**.
2. It might take a bit for Packet Tracer to **converge** on the new address, so fast forward if needed.
3. I should get a message saying **Welcome to Skills for All**.
4. The completion percentage should be **100%**. If not, **check results** to see what's missing.

Then I'm supposed to do the same test on the **office PC** and the **bedroom PC**. For extra practice, add a tablet or smartphone from the **End Devices** menu, connect it, configure it, and test it against the Skills for All server.

### The lab values (practice only)

| Setting | Value |
|---|---|
| Default router login | **admin** / **admin** |
| New router password | **MyPassword1!** |
| Max users | **10** |
| Wireless band | **2.4 GHz** |
| Network name (SSID) | **MyHome** |
| Security mode | **WPA2 Personal** |
| Passphrase | **MyPassPhrase1!** |
| Test address | **skillsforall.srv** |

Those passwords are lab examples, so I shouldn't reuse them on a real network.

**Connecting the dots:**

- This is basically what Shridhar did to Kishori's router in the Module 4 intro: **log in, change the default password, and set up wireless security**. Default credentials are public knowledge, which is why changing them matters.
- "Pre-shared key" is the **passphrase** from 3.2.3, which was the "wireless password."
- **WPA2** is the encryption recommended back in 3.2.1 and 4.3.2.
- The router's IP address is the **default gateway**, which I think is what the PC uses to reach anything outside the local network.

## What I want to remember

- **First setup:** use a wired connection from my computer to a **LAN port** (never the **Internet** port). The computer should get an IP address automatically from the router's **DHCP server**.
- Cable modem connections use a **coaxial** terminal, and DSL uses an **RJ-11** phone-style port.
- **Design questions:** what should I name my network (no brand or model in the SSID), what devices will connect (use **legacy/mixed mode** if some are older), and how do I add new devices (consider **guest access**).
- **Setup steps:** log in with the **default gateway** address, **change the default password**, set the **SSID**, turn on **WPA2 Personal**, set a **passphrase**, and **save settings** after every change.
- **Test it:** connect a device wirelessly, check that it gets an IP address, and test with a web page.
