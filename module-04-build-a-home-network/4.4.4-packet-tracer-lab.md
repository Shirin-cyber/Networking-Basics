# Packet Tracer Lab: Configure a Wireless Router and Clients

> Module 4: Build a Home Network · Activity 4.4.4

## The scenario

I'm playing a networking student helping a friend, **Natsumi**, get her new home connected to the **cable TV network**. The job:

1. Connect the right cables to the right devices.
2. Set up the **home wireless router** so it hands out IP addresses to everything on the network.
3. Set up a **wireless LAN** for her home.

The lab has three parts: **connect the devices**, **configure the wireless router**, and **configure IP addressing and test connectivity**.

---

## What I'm building

```
   Cable outlet (coax from the cable company)
          |
   [ Cable splitter ]
      |           |
    [ TV ]   [ Cable modem ]
                  |
        [ Home wireless router ]
        /         |          \
 [ Office PC ] [ Bedroom PC ] ~ ~ [ Laptop ]
   (wired)       (wired)         (wireless)
```

The cable company sends **internet and TV over one coaxial cable**. The **splitter** separates them, so TV goes to the TV and internet goes to the cable modem. This is the cable connection from 2.3.3, but built by hand.

### Cabling

| From | To | Cable |
|---|---|---|
| Splitter (Coaxial1) | Cable modem (Port 0) | Coaxial |
| Splitter (Coaxial2) | TV | Coaxial |
| Cable modem (Port 1) | Router (**Internet** port) | Copper straight-through |
| Office PC (FastEthernet0) | Router (GigabitEthernet 1) | Copper straight-through |
| Bedroom PC | Router (GigabitEthernet 2) | Copper straight-through |

A couple of things clicked here:

- The router has a **built-in switch** that takes up to **four wired hosts**. That's the "Ethernet/LAN ports are the internal switch" idea from 4.1.3.
- The 4.4.3 video said to use the "remaining port" on the cable modem. Now I know that's **Port 1**, since Port 0 is already used by the splitter.
- The PCs have no wireless adapters, which is why they're wired. The **laptop** is the wireless one.

## Router configuration

| Setting | What I set it to |
|---|---|
| Max number of DHCP users | **10** (Natsumi only has a few devices and won't have lots of visitors) |
| Router admin password | Changed from the default to **MyPassword1!** |
| Wireless band | **2.4 GHz** enabled |
| Network name (SSID) | **MyHome** |
| Security mode | **WPA2 Personal** |
| Passphrase | **MyPassPhrase1!** |

These are lab practice values, so I wouldn't reuse them on a real network.

### The reasoning behind the settings

- **Why limit users to 10?** She only has a few devices, so there's no need for the router to hand out more addresses than she'll use.
- **Why change the admin password?** Default credentials on real routers are **widely known, including by threat actors**, so they should be changed right away. This is what Shridhar did for Kishori.
- **Why turn on security at all?** She lives in a **densely populated area**, so lots of people could see her network. WPA2 Personal with a passphrase keeps unauthorized people from connecting.
- **Why WPA2 Personal?** It's the **strongest security this router offers**. (Capitalization matters in the passphrase.)
- **Why not hide the SSID?** It could be hidden, but then it's **harder for guests to connect**. This matches 4.3.2: hiding it isn't real security anyway.

## IP addressing and testing

- The Office PC is switched from static to **DHCP**, so it gets an address from the router's DHCP server. The address should **start with 192**.
- The **default gateway** is the **router's address**. The lab explains it as the device that gives the home network **access to outside networks**, like the internet. (That settles my guess from 4.4.3.) It's also the address I type into the browser to reach the router's setup page.
- The **laptop** connects wirelessly using the passphrase as the **pre-shared key**.
- The **bedroom PC** just needs to be set to **DHCP**.

### How I know it worked

- [x] The TV shows a picture
- [x] The Office PC gets an IP address starting with **192**
- [x] The laptop connects to **MyHome** and gets an IP address starting with **192**
- [x] The Bedroom PC gets an IP address starting with **192**
- [x] **skillsforall.srv** loads on the **laptop**, the **Office PC**, and the **Bedroom PC**

If the page loads on all three devices, the wired and wireless sides both have internet access.

## Gotchas I should remember

- **Save settings on every page** of the router's setup screen, or the changes don't stick.
- Changing DHCP settings can make me **lose my connection** to the router. If that happens, reload the page, and if needed, toggle the PC between **DHCP and static** to refresh its IP address. Then log in again.
- Packet Tracer can be slow to **converge**, so when something doesn't show up yet, use **Fast Forward Time**.
